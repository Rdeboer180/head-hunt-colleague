# HeadHunt for a job search

HeadHunt builds applications from your own work and writing. Start with your current résumé, two to four roles you would consider, and either a few examples of your writing or answers to a short interview. The skill turns those into a private evidence and voice profile and three or four résumé masters for the roles you can support.

## Get started

Download or clone this repository and keep its folder structure intact. Open the folder in your assistant and ask:

> Read SKILL.md and start HeadHunt onboarding. Ask me for the missing information before writing application materials.

For a later application, give the assistant the official job link and point it to your completed private profile and résumé masters.

The repository contains a [private profile worksheet](assets/candidate-profile-template.md), [four résumé templates](assets/resume-templates/), and the [skill instructions](SKILL.md). Keep your completed profile, writing samples, and application answers outside this repository.
